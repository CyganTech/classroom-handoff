Deploy to managed Chrome

Install this extension through Google Admin on a small test organizational unit. No Developer mode is needed. Both browsers must be signed into managed profiles with Chrome running.

1. Force-install the extension

In Google Admin, open Devices → Chrome → Apps & extensions → Users & browsers. Select the test OU, choose Add Chrome app or extension by ID → From a custom URL, then enter:

Set installation policy to Force install and pin the extension to the browser toolbar if offered. Save.

Signed CRX package · Release metadata · SHA-256 checksums

2. Set the server policy

The handoff backend runs on your Docker host. GitHub Pages serves only these installation files. Enter its HTTPS origin below to generate the JSON for the extension’s Policy for extensions field in Google Admin.

No secrets are needed in this policy. Never enter device bearer tokens, pairing codes, or a private signing key here.

3. Pair and test

On each Chromebook open chrome://policy, reload policies, then check that the extension installed and BackendUrl has no policy errors. Open Classroom Handoff → Device setup, rename each browser, create a pairing code on one and enter it on the other.

Open five website tabs on the sender. Choose the receiving browser and click Handoff. Keep the receiver awake and Chrome open; its popup can stay closed.

This is a Chrome extension for a normal signed-in browser session. Adding this page as a website/PWA shortcut or kiosk app does not provide tab handoff functionality.
